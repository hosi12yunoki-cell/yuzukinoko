# 柚木さんのポートフォリオ（GitHub Pages用スターター）

## 使い方（最短）
1. このフォルダを新規リポジトリにアップロード（Public推奨）。
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**
   - Branch: `main` / folder: `/ (root)` を選択。
3. 数十秒後、`https://<あなたのユーザー名>.github.io/<このリポジトリ名>/` で公開されます。

## 画像の差し替え
- `images/` に作品を入れて、`index.html` 内の `src="./images/〇〇.jpg"` を置き換えてください。

## 備考
- `./.nojekyll` はJekyll処理を無効化するための空ファイルです。
- R-18作品は別ページに分離し、年齢確認や注意書きを追加してください。
