# シンプル自己紹介サイト（1ページ）

HTMLとCSSだけで作った、初心者向けの自己紹介サイトです。
やさしいパステル調のデザインで、スマホでも見やすいように作っています。

## ファイル構成（初心者向け）

```text
yuzuki-atelier-portfolio-starter/
├─ index.html   ← ページの内容（文章・見出し・リンク）
└─ style.css    ← 見た目（色・余白・スマホ対応）
```

- **index.html**
  - サイトの「中身」を書くファイルです。
  - タイトル、自己紹介文、好きなもの、画像スペース、SNSリンクを配置しています。
- **style.css**
  - サイトの「見た目」を整えるファイルです。
  - パステルカラー、カード風レイアウト、レスポンシブ対応（画面幅に応じた調整）を入れています。

## 使い方
1. `index.html` をブラウザで開く。
2. 文章を自分用に書き換える。
3. SNSリンクの `href="#"` を自分のURLに変更する。
4. 画像を使う場合は、`index.html` の画像スペースを `<img>` タグに差し替える。

## カスタマイズ例
- 色を変えたい：`style.css` の `:root` にある色変数を変更。
- フォントを変えたい：`body` の `font-family` を変更。
- セクションを増やしたい：`index.html` に `.block` を追加。
